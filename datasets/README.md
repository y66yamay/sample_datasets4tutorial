# データセット・カタログ

モデリング実習・デモ用に整備した行動データセットの一覧。各データセットは
`datasets/<name>/` 配下に自己完結した形（生データ・前処理スクリプト・整形データ・
ドキュメント）で置く。

## 一覧
| 名前 | 課題 | 対象・臨床ラベル | モデリング例 | 状態 |
|---|---|---|---|---|
| [`dezfouli_2019`](dezfouli_2019/) | 2択バンディット | MDD 34 / BD 33 / HC 34、躁・抑うつスコア | 強化学習（学習率・逆温度 等） | ✅ 整備済 |

## データセット追加の指針（メモ）
- 新しいデータの取り込みは、事前に相談・合意してから行う（自動追加はしない）。
- 追加時は既存の `dezfouli_2019/` と同じレイアウト（`data/{raw,processed}`,
  `scripts/`, `docs/`）にそろえると横断的に扱いやすい。
- 生データには出所・ライセンスを記した `data/raw/SOURCE.md` を必ず添える。

> 本リポジトリの実行環境では、外部取得は GitHub 上のリポジトリ（`git clone`）に
> 限られる場合がある（OSF・Figshare・Zenodo 等がネットワークポリシーで遮断される
> ことがある）。取得元の選定時に留意する。
